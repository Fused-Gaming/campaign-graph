# Governance

Campaign Graph is maintained by Fused Gaming, LLC with public contributions welcome under the repository license and contribution terms.

## Project principles

1. Evidence before claim.
2. Political neutrality in core tooling.
3. Reproducible provenance.
4. Conservative entity resolution.
5. Investigation-specific data stays outside generic engine logic.
6. Contradictory evidence is preserved.
7. Human review remains the publication and release gate.

## Maintainer authority

Maintainers may accept, reject, revise, or revert contributions based on technical quality, evidence integrity, licensing, security, privacy, scope, or maintainability.

## Investigation packages

Named investigations are data packages. Their inclusion does not mean the maintainers endorse any hypothesis contained in them.

Each package should be auditable independently and should expose evidence that supports, weakens, contradicts, or leaves unresolved its hypotheses.

## Changes to core evidence semantics

Changes to any of the following require explicit maintainer review:

- confidence levels
- verification statuses
- entity-resolution rules
- money-edge classification
- hypothesis outcomes
- source preservation rules
- licensing
- release/version gate

## Releases

Releases require:

- synchronized versions
- changelog entry
- tests appropriate to the change
- Rock-Hardened release evidence when available
- human approval
