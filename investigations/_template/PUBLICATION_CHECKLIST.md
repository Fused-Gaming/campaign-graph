# Public package checklist

- [ ] State scope, as-of date, methodology, and limits.
- [ ] Keep fact, inference, hypothesis, and unresolved lead distinct.
- [ ] Confirm every edge has source IDs and original URLs/record IDs.
- [ ] Confirm money edges have documented transfer evidence.
- [ ] Include contradictory evidence and plausible alternatives.
- [ ] Review identity collisions and protect unrelated people.
- [ ] Keep noncommercial license and commercial-license notice.
- [ ] Run the repository's applicable tests, validation, version checks, and pinned release gate; record actual outcomes.
- [ ] Update CHANGELOG.md for meaningful changes.
