# Investigation package template

Copy this directory to `investigations/<slug>/`, then fill the manifest and evidence registries. New investigations must be data/config only; do not add case-specific branches to the generic engine.

Start with `investigation.json`, `sources.json`, and `entities_of_interest.json`. Add nodes/edges only after source review and conservative entity resolution. Preserve unresolved values explicitly. Update findings and the changelog for substantive repository changes.
